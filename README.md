## Sobre

Página institucional de um petshop e clínica veterinária, construída como um cartão de visitas digital da marca: apresenta os serviços, os diferenciais e um formulário de agendamento validado no front-end.

Feita **sem frameworks e sem bibliotecas de JavaScript**, apenas HTML5 semântico, CSS3 (Grid, Flexbox, variáveis, `aspect-ratio`) e JavaScript puro.

## Seções

Destaque · Sobre · Serviços · Depoimentos · Dúvidas frequentes · Contato

## Recursos implementados

- Cabeçalho fixo com menu lateral no celular
- Animações de entrada com `IntersectionObserver`
- Indicadores numéricos que sobem até o valor final
- Carrossel de depoimentos com troca automática, teclado e gesto de arrastar
- Acordeão de perguntas frequentes
- Formulário com validação, máscara de telefone e contador de caracteres
- Layout responsivo em seis pontos de quebra
- Cuidados de acessibilidade (ARIA, foco visível, `prefers-reduced-motion`)

## Como visualizar

Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/anaalthoff/pet-love.git
cd pet-love
```

Não há dependências para instalar nem build para rodar.
